### Key Points

<Info>
  **Merchant Configuration**

  * The **Merchant ID** must be configured to support the selected E-Wallet payment method.

  * For the **GCash** example, the `payment_method` type must be set to `gcash`.

  * The Direct Payment API requires the transaction amount, processing currency, merchant details, return URLs, billing address, and time zone.

  * [See all supported E-Wallets...](/documentation/paymentmethods/ewallets)

  **E-Wallet Payment**

  * The Direct Payment API initiates an E-Wallet transaction and returns a payment URL for the customer.

  * For GCash, the response includes a payment page URL in the `url` and `redirecturl` fields.

  * The merchant can redirect the customer to the provided payment URL to complete the transaction using GCash.

  * The payment URL is generated when the transaction is initiated; it does not indicate that the payment has been completed.
</Info>
