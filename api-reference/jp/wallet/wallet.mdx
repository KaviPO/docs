### 主なポイント

<Info>
  **加盟店の設定**

  * \*\*加盟店ID（Merchant ID）\*\*は、選択したEウォレット決済方法に対応するように設定されている必要があります。

  * **GCash**を利用する場合、`payment_method` の `type` に `gcash` を指定する必要があります。

  * Direct Payment APIでは、取引金額、処理通貨、加盟店情報、リターンURL、請求先住所、タイムゾーンの指定が必要です。

  * [対応しているEウォレット一覧はこちら...](/documentation/paymentmethods/ewallets)

  **Eウォレット決済**

  * Direct Payment APIはEウォレット決済を開始し、顧客が決済を行うためのURLを返します。

  * GCashの場合、レスポンスの `url` および `redirecturl` フィールドに決済ページのURLが含まれます。

  * 加盟店は、顧客を返された決済URLにリダイレクトすることで、GCashを利用した決済を完了できるようにします。

  * 決済URLは取引開始時に生成されますが、URLが生成された時点では決済の完了を意味しません。
</Info>
